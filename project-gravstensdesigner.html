Building a multi tenant 3D configurator for Swedish memorial stone retailers

Gravstensdesigner is a SaaS platform I built from scratch under Veyla AB. It gives Swedish stonemason companies (stenhuggeri) a modern tool where their customers can design a gravestone in the browser, preview it in real time, and submit an order directly.

The core of the product is a Three.js powered 3D configurator where end customers choose a stone shape, select material and finish, add text with custom fonts and colors, place decorations, and see everything update live. When they are happy with the design they fill in their details and send a request to the stonemason, including a snapshot of the stone, all configuration details, and any attachments.

The platform supports three different stone types. Stenbyggare are configurable rectangular stones built with BoxGeometry where the admin sets dimensions, textures, and finishes per face. Profilstenar are organic shaped stones using ExtrudeGeometry from SVG paths, where an admin can paste an SVG path from Figma and instantly get a 3D stone. Färdiga stenar are pre made 3D models generated from uploaded photos using Meshy AI.

On the admin side, stonemason companies manage their entire product catalog. They control which stones, textures, and options are available to their customers. There is a unified stone management view with drag and drop reordering, a centralized granite texture bank, per client symbol categories for decorations, and per stone pricing with adjustable base prices and surcharges for size, material, and finish.

I processed over 40 real granite textures through a custom image quilting pipeline in Python to create seamless 2048x2048 textures, flattening lighting gradients so they tile correctly on 3D geometry.

The decoration system supports manual uploads, AI generated decorations using OpenAI gpt-image-1 with transparent backgrounds, and a classic symbol library that is database backed and organized per client with categories. AI generation runs three sequential edge function calls with a real time progress bar.

The tech stack is React 18, TypeScript, Vite, and Tailwind on the frontend, with Three.js for all 3D rendering. The backend runs on Supabase with five edge functions handling things like order emails through Resend, AI decoration generation, and 3D model generation through Meshy. Hosting is on Vercel with analytics built in.

The platform is multi tenant from day one. Each stonemason company gets their own branded experience under a unique URL slug. Their logo is clickable, their stone catalog is fully customized, and all orders go to their notification email.

I built the entire product solo, handling everything from the 3D rendering and shader work to the admin panel, the order flow, the email templates, the AI integrations, and the texture processing pipeline.
